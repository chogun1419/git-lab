ในการทำ Lab นี้ ได้ใช้ AI ช่วยอธิบายการตรวจสอบเงื่อนไข R <= 0 และร่างโค้ด Unit Test เพิ่มเติม แต่ได้ทำการตรวจทาน logic และรัน unittest ด้วยตนเองทุกครั้งก่อน commit

ระหว่างทำพบข้อผิดพลาดตอนสั่ง push เนื่องจากโค้ดบน GitHub ไม่ตรงกับในเครื่อง แก้ไขโดยการสั่ง git pull ลงมาก่อนแล้วค่อย push ใหม่

ความแตกต่างของ Commit, Push และ Clone:
- Commit คือการบันทึกประวัติการแก้ไขไว้ในเครื่อง Local
- Push คือการส่ง Commit จากเครื่อง Local ขึ้นไปเก็บไว้บน GitHub Remote
- Clone คือการดาวน์โหลดไฟล์และประวัติ Git ทั้งหมดจาก GitHub มาไว้ในเครื่องใหม่

เหตุผลที่ต้องตรวจ Tests บนเครื่องใหม่ เพื่อย้อนเช็กว่าสภาพแวดล้อมระบบและโค้ดพร้อมทำงานได้อย่างถูกต้อง 100%
