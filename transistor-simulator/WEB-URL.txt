Transistor DC Bias Simulator - Web URL
======================================

Local web app (run on this machine)
-----------------------------------
  http://127.0.0.1:5000/

  Start the server first:
    cd transistor-simulator
    python app.py

  หมายเหตุ: 127.0.0.1 คือ localhost เปิดได้เฉพาะเครื่องที่รันเซิร์ฟเวอร์
  และใช้ได้เฉพาะขณะที่เซิร์ฟเวอร์ยังทำงานอยู่ (ไม่ใช่ public URL)
