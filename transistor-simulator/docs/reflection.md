# Reflection — Transistor DC Bias Simulator

## สิ่งที่ได้ทำ

งานนี้ต่อยอดจาก Lab 01 (เครื่องคำนวณวงจร DC แบบ CLI) มาสู่เว็บแอปพลิเคชัน
ที่คำนวณจุดการทำงานของทรานซิสเตอร์ เป้าหมายคือแยกสูตรวิศวกรรมออกจากส่วนเว็บ
ให้ชัดเจน เพื่อให้ตรวจสอบความถูกต้องได้ด้วย unit test ก่อนเชื่อผลบนหน้าจอ

## การใช้ AI

- ใช้ AI ช่วยร่างสมการ Thevenin ของวงจรแบ่งแรงดัน และช่วยตรวจว่าลำดับการคำนวณ
  V_BB → R_B → I_B → I_C → V_CE ถูกต้อง
- ใช้ AI ช่วยร่างชุดทดสอบ ทั้งค่า known-value, กรณี cutoff/saturation
  และกรณีอินพุตผิด
- **ไม่ได้เชื่อผลจาก AI โดยตรง** — ตัวเลขทุกตัวใน `docs/validation.md`
  ถูกคำนวณซ้ำด้วยมือและเทียบกับผลที่โปรแกรมคืนมา

## บทเรียนที่ได้

1. **เขียน test ก่อนแล้วเห็นมัน fail สำคัญจริง** ตอนแรกค่า I_C ที่คำนวณมือ
   ปัดเศษผิด test จึง fail ทำให้รู้ว่าต้องยึดค่าจากสมการเต็ม ไม่ใช่ค่าที่ปัดแล้ว
2. **กรณี Saturation เผยจุดอ่อนของสมการ** สมการไบแอสให้ V_C ติดลบถึง −412 V
   ซึ่งเป็นไปไม่ได้ทางฟิสิกส์ จึงต้องจำกัดกระแสที่ I_C(sat) แล้วคำนวณแรงดันใหม่
   เป็นตัวอย่างว่าคำตอบที่ "ถูกตามสูตร" ไม่เท่ากับคำตอบที่ "ใช้งานได้"
3. **การแยก layer ทำให้ debug ง่าย** เมื่อตัวเลขบนหน้าจอผิด สามารถไล่ได้ว่า
   ผิดที่ `dc_bias.py` หรือที่การแสดงผล โดยไม่ต้องเดา
4. **การคงค่าที่กรอกไว้เมื่อ error** เป็นรายละเอียดเล็ก ๆ ที่ส่งผลต่อประสบการณ์
   ใช้งานมาก ผู้ใช้ไม่ต้องพิมพ์ค่าทั้งฟอร์มใหม่เพราะพิมพ์ผิดช่องเดียว

## ปัญหาที่พบและวิธีแก้

| ปัญหา | วิธีแก้ |
|---|---|
| ค่าคาดหวังใน test ปัดเศษไม่ตรงกับสมการ | คำนวณใหม่จากสมการเต็ม แล้วใช้ tolerance ที่ระบุชัดเจน |
| ผลเฉลย Saturation ติดลบ | จำกัดกระแสที่ I_C(sat) และคำนวณ V_C, V_E ใหม่ |
| ข้อความไทยเพี้ยนเมื่อพิมพ์ผ่าน console | ตรวจว่าไฟล์ template เป็น UTF-8 จริง และทดสอบด้วยการเทียบ string ใน Python แทนการดูจาก console |
| ตัวอักษรไทยใน terminal แสดงผลไม่ได้ | ไม่ใช่บั๊กของแอป แต่เป็น codepage ของ terminal |

## สิ่งที่อยากพัฒนาต่อ

- เพิ่มวงจรไบแอสแบบ fixed bias และ collector feedback
- วาด load line พร้อมจุด Q ด้วย SVG
- เปรียบเทียบ β หลายค่าเพื่อดูความเสถียรของจุดไบแอส
- เพิ่มการบันทึกผลเป็น CSV เพื่อใช้ในรายงานแล็บ
